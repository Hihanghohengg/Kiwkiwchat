# Laporan Audit Final Kelengkapan Metode & Bukti Ancaman SSDLC (T-01 s/d T-16) — Kiw Kiw Chat

Dokumen ini memuat hasil audit komprehensif terhadap seluruh 16 skenario ancaman Trike Threat Modeling (T-01 s/d T-16) pada proyek Kiw Kiw Chat. Audit ini memvalidasi keabsahan metodologi verifikasi, keberadaan eksekusi nyata, artefak raw evidence, serta kelayakan penyajian dalam manuskrip paper penelitian ilmiah.

## 2. Catatan Audit Tinjauan Kode (Code Review Records)

Untuk skenario ancaman yang mencakup metode `CODE_REVIEW` sebagai salah satu komponen verifikasi, berikut rincian catatan audit formal:

- **CR-01 (T-03 - Backend Signaling Isolation)**:
  - Bagian kode yang diperiksa: `backend/main.py:websocket_endpoint` dan `frontend/src/signaling.js`.
  - Properti keamanan yang dicari: Memastikan relay server tidak menerima, memproses, atau menyimpan plaintext pesan maupun private keying material.
  - Hasil pemeriksaan: Terverifikasi bahwa payload WebSocket signaling hanya meneruskan format JSON pertukaran SDP/ICE dan ciphertext enkapsulasi KEM publik.
  - Keterbatasan: Server dapat menghentikan lalu lintas komunikasi (Denial of Service), tetapi tidak mampu mendekripsi muatan obrolan.

- **CR-02 (T-06 - Memory Pointer Dereference)**:
  - Bagian kode yang diperiksa: `frontend/src/crypto.js` (fungsi `decapsulateMLKEM` dan `deriveHybridKeys`).
  - Properti keamanan yang dicari: Penghapusan referensi pointer variabel kunci (`_pqSecretKey = null`, `_roomSecret = null`) setelah derivasi kunci selesai.
  - Hasil pemeriksaan: Logika dereferensi pointer diterapkan dengan benar pada alur kode.
  - Keterbatasan: Engine V8 mengelola alokasi memori melalui Garbage Collector; tidak ada instruksi *deterministic physical RAM zeroization*.

- **CR-03 (T-07 - URL Fragment Isolation)**:
  - Bagian kode yang diperiksa: `frontend/src/main.js` (fungsi `extractRoomCredentials`).
  - Properti keamanan yang dicari: Memastikan room secret diekstrak secara eksklusif dari `window.location.hash` dan tidak pernah disertakan pada path URL atau query string HTTP.
  - Hasil pemeriksaan: Sesuai spesifikasi RFC 3986, fragment `#` tidak dikirimkan oleh browser pada request HTTP GET atau header HTTP Referer.
  - Keterbatasan: Pengguna yang membagikan URL secara fisik/lengkap tetap mengekspos kunci kepada pihak yang menerima tautan tersebut.

- **CR-04 (T-10 - Browser Storage Teardown)**:
  - Bagian kode yang diperiksa: `frontend/src/main.js` (fungsi `clearRoomStorage`) dan `frontend/src/chat.js`.
  - Properti keamanan yang dicari: Penghapusan seluruh kunci obrolan dari `sessionStorage` dan `localStorage` saat sesi diakhiri.
  - Hasil pemeriksaan: Pemanggilan `sessionStorage.clear()` dieksekusi saat teardown sesi obrolan.
  - Keterbatasan: Efektif pada API Web Storage; sisa residu memori browser host yang belum ditimpa oleh OS berada di luar kendali aplikasi web.

- **CR-05 (T-11 - CORS Configuration Review)**:
  - Bagian kode yang diperiksa: `backend/main.py` (baris 114–119).
  - Properti keamanan yang dicari: Memastikan konfigurasi `CORSMiddleware` menggunakan whitelist `ALLOWED_ORIGINS` terdefinisi dan tidak menggunakan wildcard permissive `*` saat kredensial diizinkan.
  - Hasil pemeriksaan: Konfigurasi CORS menerapkan `allow_origins=ALLOWED_ORIGINS` secara eksplisit.
  - Keterbatasan: Perlindungan CORS ditegakkan oleh browser client; request langsung via script/cURL memerlukan otorisasi token signaling.

1. **Seluruh 16 Skenario Ancaman (T-01 s/d T-16) memiliki metode verifikasi yang BENAR-BENAR DIJALANKAN (`Metode Dijalankan = YES`)**.
2. **Tidak ada ancaman berstatus `NOT_TESTED`**. Seluruh klaim didasarkan pada eksekusi pengujian dinamis, pengujian otomatis, SAST/DAST scanner, atau tinjauan kode terstruktur.

   - **PASS / PASS (0 High)**: 13 Ancaman (`T-01`, `T-02`, `T-03`, `T-04`, `T-05`, `T-07`, `T-09`, `T-10`, `T-11`, `T-12`, `T-13`, `T-14`, `T-15`).

4. **Kelayakan Masuk Paper Ilmiah**:
   - **Seluruh 16 Ancaman LAYAK dimasukkan ke dalam paper ilmiah**.
   - Ancaman berstatus `PARTIAL` dan `OPEN_MEDIUM` disajikan secara transparan di dalam bab Hasil & Pembahasan serta sub-bab Batasan Penelitian (*Limitations*).
